# SkillDZ Backend

Base serveur prête pour comptes, catalogue, commandes, statut de paiement et déblocage.

Lancer:
1. Node.js 20+
2. copier `.env.example` vers `.env`
3. définir un JWT_SECRET long et aléatoire
4. `npm install`
5. `npm start`

Le paiement Edahabia réel n'est PAS activé dans ce projet. Le webhook est un emplacement sécurisé à compléter avec les paramètres officiels du webmarchand. Ne mets jamais une clé privée dans le HTML ou un dépôt GitHub public.
